# Original deployment scripts
These reference scripts target the original venicesciencebowl Pi account,
the /home/venicesciencebowl/science-bowl-buzzers installation and direct Ethernet
192.168.77.2:8080. Review and adapt paths, account names and interfaces first.
Scripts may modify network profiles, install services or laptop startup helpers.
setup-pi.sh expects an existing virtual environment and data/one_channel.db.
It is not a clean-install script. The desktop simulator needs none of these.
Browser auto-opening requires a helper on each laptop.
